# ESP32 and Raspberry Pi example project

Programming examples for ESP32 micro controllers and Raspberry Pi 5 with C/C++ and Platform.IO

This repository contains C/C++ code that you can use to develop shared code for ESP32 and Raspberry Pi 5 with Platform.IO and Unity and gtest.
